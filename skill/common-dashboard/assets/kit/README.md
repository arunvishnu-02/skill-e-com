# dashboard-kit copy-in (v0.1.0)

Copy this folder into a project (e.g. src/dashboard-kit/) when @dashboard-kit/ui cannot be installed.

- Import `./styles.css` once, and `./src/index` for components.
- Peer deps: react >= 18, react-dom >= 18. No other dependencies.
- Do not edit these files per client; theme via ClientTheme.
- Generated by scripts/sync-skill.mjs. Source of truth: packages/ui.
