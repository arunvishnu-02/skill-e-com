# Example client themes

`client-themes.ts` has three examples (also used by `apps/starter`):

| Theme | Input | Shows |
|---|---|---|
| `ak57` | `masterTheme` | Exact Figma reference (fixture only, never ship to a client) |
| `oceanClinic` | `primary` only | Fully generated accessible palette |
| `verdeFoods` | primary + secondary + accent, `mode: "dark"` | Custom brand in dark mode |
